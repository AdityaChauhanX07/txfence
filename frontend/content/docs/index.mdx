# txfence

**txfence** is a policy enforcement SDK for autonomous agents. It sits between your agent's decision-making layer and the blockchain, intercepting every action and evaluating it against your declared policies before execution.

No more runaway agents. No more unintended transactions.

## Packages

| Package | Description |
|---|---|
| `@txfence/core` | Policy engine and pipeline runner |
| `@txfence/evm` | EVM chain adapter (Ethereum, Polygon, Arbitrum, Base…) |
| `@txfence/solana` | Solana adapter with SPL token support |
| `@txfence/cosmos` | Cosmos SDK / IBC adapter |
| `@txfence/policy-dsl` | Human-readable policy language |
| `@txfence/simulate` | Dry-run simulation without on-chain state |
| `@txfence/audit-log` | Tamper-evident structured audit trail |
| `@txfence/rate-limiter` | Token/value rate limits with sliding windows |
| `@txfence/allowlist` | Address and contract allowlist/denylist |
| `@txfence/multisig` | Require N-of-M approvals for high-value actions |
| `@txfence/circuit-breaker` | Halt execution on anomaly detection |
| `@txfence/monitor` | Real-time telemetry and alerting hooks |

## Why txfence?

Autonomous agents execute transactions faster than humans can review them. A single misconfigured agent can drain a treasury, bypass access controls, or trigger cascading failures across DeFi protocols in seconds.

txfence gives you:

- **Declarative policies** — define intent once, enforce everywhere
- **Chain-agnostic pipeline** — same policy syntax across EVM, Solana, and Cosmos
- **Zero-overhead simulation** — validate every action before it hits the chain
- **Tamper-evident audit logs** — full trace of every decision, pass or fail
- **Circuit breakers** — automatic halt on anomaly detection
